# Verdugos Los Santos — interaktivní mapa

Základní frontend pro komunitní mapu GTA.

## Spuštění

Stačí otevřít `index.html` v prohlížeči.

## Struktura

- `index.html` — hlavní stránka
- `style.css` — vzhled
- `app.js` — základní zoom + posouvání mapy
- `assets/logo.png` — logo
- `assets/mapa.png` — mapa

Další krok můžeme postavit nad tuto kostru: přidávání bodů, kategorií, území, editaci, ukládání dat a následně napojení na GitHub/backend.
